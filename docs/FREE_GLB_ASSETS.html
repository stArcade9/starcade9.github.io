🔧 How to Use GLB Files in Nova64

  1. Download GLB files to your project:

bash mkdir -p /path/to/nova64/models cd /path/to/nova64/models # Download your GLB files here

  1. Load in Nova64 code:

```javascript export async function init() { // Load GLB model const fox = await loadModel('/models/Fox.glb', [0, 0, 0], 1.0);

 // Or with options
 const player = await loadModel(
   '/models/character.glb',
   [0, 2, 0], // position
   2.0 // scale
 );

} ```

  1. Animate GLB models (if they have animations): javascript export function update(dt) { // Play animation nova64.scene.playAnimation(modelMesh, 'Walk', dt); }
