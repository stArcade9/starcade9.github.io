## 2026-11-06 - WASM core, eMU, QWEN Arcade, Babylon restore, release prep

Topic seed for MemPalace: `nova64-2026-11-wasm-emu-qwen-babylon`

AAAK:

- **Anchor:** Long session that shipped the WASM libretro core into the web
  OS, fixed carts broken by the bare-globals removal, added the QWEN Arcade,
  made eMU work on mobile, and restored the Babylon backend. PRs #25-#32 plus
  `fix/babylon-backend`.
- **Knowledge (things that cost time, so the next agent doesn't pay twice):**
  - **Bare globals are gone on the web** (6267ecb3). Carts must destructure
    from `nova64.*`. The libretro core still installs bare globals, so a cart
    can work on RetroArch and throw `X is not defined` in the browser. Check
    with a static pass over `NAMESPACE_MAP` (`runtime/namespace.js`). Mind the
    regex trap: `(^|[^.\w$])name\(` consumes the char before `if (btn(` and
    misses it; use a lookbehind `(?<![.\w$])`. Use `Object.hasOwn` so
    `constructor` isn't treated as an API name.
  - **Carts from retroarch/games** (b9b9995a) use ~25 core-only APIs; see
    BACKLOG.md "Core-only APIs in web carts".
  - **CRLF:** many carts and docs use CRLF. Python text-mode I/O converts to
    LF and rewrites the whole file in the diff. Use `newline=''` and keep the
    file's own line ending.
  - **lint-staged prettier** reformats whole staged carts. Split a pure
    formatting commit from the fix commit so the fix stays reviewable.
  - **dist/ drift:** `pnpm test` checks that dist/examples and dist/runtime
    mirror source. After switching branches run `pnpm sync:dist` (carts) and
    `pnpm build` (runtime), or the pre-push preflight fails for no real reason.
    `dist/*.html` get new asset hashes on every build; don't commit that churn.
  - **Playwright suite is not in CI** and had gone stale: it waited on
    `globalThis.createCube`. Fixed the wait plus a test-only shim that mirrors
    `nova64.*` functions onto globalThis inside page.evaluate. Its
    `playwright.config.js` reuses whatever listens on :3000. On this Mac a
    Python server holds :3000, so point a temp config at :5173.
  - **Pre-existing on main** (not regressions): api-compatibility threejs
    raycastFromCamera / setPBRProperties / scene.traverse; particle-fireworks
    (core-only APIs).
  - **Babylon root cause:** meshOptions were never implemented for Babylon,
    so `nova64.scene` omitted setMeshEmissive and friends and every cart
    crashed in init. Also `normalizeColorValue` decoded rgba8() BigInts with
    `Number(bigint)` (wrong; RGBA64 needs >>48/>>32/>>16 and /257). Once
    emissive worked, bloom (x5 weight, 0.3x threshold) blew frames out to
    white. Recalibrated to weight = strength x 0.35, threshold >= 0.7.
  - **OS shell:** desktop eMU and mobile eMUI share
    `os9-shell/src/apps/nova64-library.tsx` (player, QWEN shelf, library).
    URL helpers live in side-effect-free `utils/retroarchWeb.ts`, because
    importing `retroarch-web-app.tsx` registers a desktop app. Mobile is a
    separate React app (`src/mobile/`, chosen when the UA is mobile or width
    <= 900) with its own app ids (eMU = `emui`); deep links map `emu` to
    `emui`. Portrait phones get a "Better in widescreen" gate, so tests must
    tap "Continue in portrait anyway" or use landscape.
  - **Dev-server redirect:** vite.config.js redirected /os9-shell/ ->
    /os9-shell/index.html and dropped the query string. Fixed so `?app=` links
    work on :5173. `localhost:5173/os9-shell` serves the prebuilt
    `public/os9-shell` (rebuild with the os9-shell vite build + copy dist).
  - **RetroArch web player:** `?cart=message` + postMessage
    (`nova64:ready` / `nova64:cart`) for dropped files, since a cross-origin
    iframe can't fetch the shell's blob: URLs. The touch gamepad sends keys
    RetroArch already maps (arrows, Space, Z->B, X->A, Enter->Start), with
    `keyCode`/`which` defined on the synthetic KeyboardEvent for emscripten.
  - **QWEN Arcade:** `examples/QWEN/arcade.json` is generated by
    `scripts/build-qwen-arcade.mjs` from each game's meta.json. The
    dashboard, console shelf and eMU all read it. Covers are
    `examples/QWEN/blog/<id>-title.png`.
  - **Git worktrees** keep test servers stable while editing other
    branches. Symlinked node_modules work for vite/tsc/node, but `pnpm <script>`
    refuses (its deps check won't touch a node_modules outside the project).
    Run the script's command with node directly.
  - **Auto mode** blocks `gh pr merge`, force-push, repo settings changes
    and glob `rm -rf`. Merges into main are the user's call. For stale tracked
    bundles, `git rm` an explicit list instead.

- **2026-11-06 — Godot: 104/104 carts clean (PRs #35, #36, #37)**
  - **GDExtension teardown:** `Object::~Object` runs *after* `Node::~Node`, so a
    destructor that touches children reads freed memory (SIGABRT at exit).
    Do cleanup in `NOTIFICATION_PREDELETE`. Function-static `Ref<Shader>` /
    `Ref<ImageTexture>` outlive the RenderingServer and leak RIDs. Keep them
    at file scope and release them in `_shutdown_runtime()`.
  - **Core-only APIs:** carts ported from retroarch/games call libretro-core
    functions (printBold, hline, setSkyColor, bursts, wave manager...).
    `runtime/core-compat.js` implements them once on host primitives. The
    Godot shim can't import modules, so it holds a marker-delimited copy:
    run `node scripts/sync-core-compat.mjs` after editing (prettier reformats
    the module on commit, so re-sync then too). `tests/test-core-compat.js`
    fails on drift. The shared code never inspects colours, because rgba8 is a
    BigInt on web and an object/number in Godot.
  - **Godot lighting parity:** Three.js PointLight decays inverse-square
    (decay 2); Godot's OmniLight default attenuation is 1. Pass
    `attenuation: 2` or high intensities wash surfaces white.
  - **Godot media:** `VideoStreamPlayer.play()` errors when the host isn't in
    the tree yet (carts start media in init()); use `set_autoplay(true)`.
  - **HDR skies in Godot:** `Image::load_from_file` reads .hdr directly, with
    no import step. `godot_project/assets/sky` links `public/assets/sky`.
    Godot writes `.import` sidecars next to assets, which are now gitignored.
