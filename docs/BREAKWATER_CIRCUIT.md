# Breakwater Circuit — The Spillway

Original Nova64 cartridge, developed on `main`, November 9, 2026. Source:
`examples/breakwater-circuit/`; identical runtime files and models are mirrored into
`dist/examples/breakwater-circuit/`.

## Play

```sh
nvm use
pnpm dev --host 127.0.0.1 --port 3199
```

- Console: <http://127.0.0.1:3199/console.html?demo=breakwater-circuit>
- Direct preview: <http://127.0.0.1:3199/hero-embed.html?demo=breakwater-circuit&w=960&h=540>
- Choose Quick Race (five rivals) or Time Trial. Both run three laps. Results offer immediate retry.

| Action                 | Keyboard          | Standard gamepad    | Landscape touch           |
| ---------------------- | ----------------- | ------------------- | ------------------------- |
| Throttle               | W / Up / Z        | X                   | D-pad Up, or Auto         |
| Steer                  | A/D / Left/Right  | Left stick          | D-pad Left/Right          |
| Airbrakes              | Q/E independently | LB/RB independently | Hold B with Left/Right    |
| Brake                  | Down / X          | Y                   | B / D-pad Down            |
| Spend Slip Charge      | Space             | B                   | A                         |
| Start / pause / resume | Enter             | A / Start           | START; tap menu options   |
| Recovery (+3 seconds)  | R                 | —                   | —                         |
| Mute / auto throttle   | M / T             | —                   | Tap SND / AUTO in top bar |

Auto throttle defaults on for touch devices. On pause, tap Resume or Retry.
Local best times are stored separately for each mode through `nova64.data`.
Storage failure is handled by the runtime. Audio uses the runtime synth; the original
136 BPM electro phrase combines a syncopated kick/snare pattern, bass, arpeggios,
engine pitch and wind. Mute suppresses new voices; short existing voices finish naturally.

## Course and handling

`race.js` contains the closed, sampled course and pure 120 Hz simulation. The same
course positions drive road slabs, banks, barriers, eight ordered checkpoints,
boost pads, AI waypoints, minimap and camera. Progress is continuous and unwrapped;
it never chooses a globally nearest road segment. The customs straight, crane
sweeper, container chicane, seawall crest/descent and lighthouse hairpin each have
an identifiable landmark.

Steering changes heading; lateral velocity catches up with inertia. Airbrakes add
turning authority and lateral damping. Hover follows a damped spring. Light wall
scrapes retain steering, while high lateral-speed impacts cost more momentum.
Recovery returns to the last valid gate, adds three seconds and invalidates the
current clean sector. Forward, nearby, in-corridor crossings must visit every gate
in order. Reversing over the finish, skipping a gate and recovering cannot grant a lap.

A clean marked bend, useful speed and a straightened exit earn half a Slip Charge.
Each bend can pay once per lap. Bank a full charge, then spend it for a 1.7-second
boost. Cyan chevron strips give an immediate separate kick and sound. Rival ships
follow distinct preferred lanes; ship-to-ship contact is non-solid in this release.

## Visual direction

The owner steered the initial muted industrial palette toward vivid electric blue,
acid green, cyan and violet. Yellow/orange accents were removed. The port identity
remains, now lit as an after-hours racing league: animated aurora, twisting open
light-vaults, flowing roadside ribbons, emissive rails, and blue tide bands. The
asymmetric technical UI and custom league symbols are original, influenced by the
racing graphic language of The Designers Republic. No Wipeout graphics, models,
music or code are included.

Six original split-delta hydrofoil GLBs are generated by
`scripts/build-breakwater-assets.mjs`. They use sculpted flat-shaded hulls, raised
canopies, swept foils, racing stripes and separate dynamic engine trails. Rebuild:

```sh
pnpm exec node scripts/build-breakwater-assets.mjs
```

The primary renderer is Nova64's existing Three.js path, with grouped `nova64.*`
APIs throughout. Static scenery is instanced by material; the flowing ribbons use
one additional instanced batch. Post-processing uses bloom, FXAA, subtle edge
chromatic separation and vignette. The camera stays low with course lookahead,
spring-like position smoothing and a small boost FOV increase.

## Reference review

[Wipeout's gameplay/development account](<https://en.wikipedia.org/wiki/Wipeout_(video_game)>)
links differentiated craft handling, track pickups, electronic music and league
branding into one racing identity. The useful design lesson here is that handling,
audio and graphics should reinforce the same sense of momentum; Breakwater keeps
its first release focused on racing lines rather than weapons.

[PhobosLab's viewer](https://phoboslab.org/wipeout/) ran in Chromium; both Free and
Fly-Through were exercised. Repeated rails and nearby structures provide strong
parallax, while camera lookahead matters more than added effects at a crest.
The [technical article](https://phoboslab.org/log/2015/04/reverse-engineering-wipeout-psx)
and [source](https://github.com/phoboslab/wipeout) separate scenery, track surfaces
and section-linked camera paths. `createCameraSpline` and `updateSplineCamera`
show section traversal, forward targeting and damping; its README also warns about
jump handling. Breakwater uses original course code and tests its own crest.

A full-race [video reference](https://www.youtube.com/watch?v=f3SlOZGv0Ps) was found,
but a complete video playback was not verified. The Nova64 homepage was accessible;
`https://nova64.io/docs` failed through the web reader. API contracts were therefore
checked against the live repository source: input mapping, audio presets, storage,
model loading, instancing, skybox, effects and cart loader.

## Verification and exports

```sh
pnpm exec node --test tests/test-breakwater-racing.js
pnpm exec node tests/racing-browser.mjs
pnpm test
pnpm build:nova breakwater-circuit
```

The regression suite checks backward/invalid finish crossings, skipped gates,
recovery, light/heavy impacts, charge banking, pad farming, all AI finishers and
fixed-step equivalence at 30/60/120 presentation FPS. The deterministic three-lap
comparison is 59.87 seconds / zero contacts for clean braking and timed boosts,
versus 65.55 seconds / 18 contacts for full throttle without braking or boost.

Browser evidence and exact tested profiles are in
`tests/artifacts/racing/browser-report.json`; screenshots include the grid,
sweeper, crest, hairpin and finish. Full-race runs use a test-only input driver
through the real cartridge update path; separate checks use DOM keyboard/touch
and `navigator.getGamepads` emulation. No test controls ship in the cartridge.
Both cartridges also passed Babylon initialization from the production preview
(`launch-smoke.json`); full Babylon races were not tested. The first dev-server
Babylon attempt hit stale Vite shader-module URLs; the production build avoided
that optimizer-cache issue. Physical gamepad/phone hardware, Firefox, Safari,
native Godot and RetroArch are
not certified by these checks. Audio was exercised programmatically, not audited
through speakers. The primary verified target is the browser/Three.js runtime.

The generated review export is `dist-lemon/racing/breakwater-circuit.nova`.
It contains code, simulation, metadata, manifest and all six models. Native host
execution of the package is unverified; package generation alone is not a native
compatibility claim. `pnpm build:nova` regenerates the bundle under the cart folder.

MemPalace is configured for the Windows/WSL counterpart. This Mac lacks `~/ai-tools`,
so memory wake-up is unavailable here; the working Windows configuration was left
intact. Current source and Git history were used instead. See `AGENTS.md`.

The shared input alias regression discovered during controller verification was
fixed separately: A/Start and B/Select now combine their states rather than later
unpressed aliases overwriting face-button presses. `pnpm test:input` reproduces
the original failure and verifies hold/release/press-edge behavior.

Final Chromium 147 browser checks finished and retried Quick Race and Time Trial
(60.075 seconds under the 60 Hz test driver), verified pause/mute/local bests,
and exercised keyboard, emulated touch and emulated gamepad. Profiles: 960×720,
1440×810 and 844×390 touch; the automated comparison framebuffer is 640×360
scaled into those viewports. Direct previews were also inspected at 960×540.
No browser/cart errors were recorded in the final complete run.
