# Nova64 0.5.3 npm release preparation

Prepared October 3, 2026. This supplements the earlier
[v0.5.3 tag notes](v0.5.3.md); it does not indicate a new npm publication.
At verification, npm's latest version was 0.5.2 and 0.5.3 was available.

## Publication result — October 3, 2026

After browser authentication, `pnpm publish` exited successfully and reported
`Published package nova64@0.5.3`. The submitted archive is 125,295,565 bytes
with 931 files and SHA256
`ff96734bde7097534718f0494d00962b5f7a9fda3e1af0142cdbb581f258186c`.
Public registry checks immediately afterward still returned 0.5.2 as latest
and no metadata for 0.5.3. Registry availability and the remote checksum remain
unconfirmed; the successful command result alone is not a download verification.

## Changes reviewed

- Console menus omit Hello 3D, Mystical Realm, and FPS Action Mode. Their cart
  files and direct loading support remain available.
- The npm package includes the source cart runner. Template discovery uses
  bundled `dist/examples` when installed without a repository checkout.
- Both scaffold commands select the installed version, with `NOVA64_VERSION`
  as an override. The starter uses `nova64.*` APIs instead of missing globals.
- The development server redirects with the cart path in the browser URL;
  previously an internal rewrite left the runtime loading the default demo.
- Public builds exclude the private operations document and its generated HTML,
  including stale copies from previous builds.
- NOA remains an optional peer, avoiding an automatic Git-based transitive
  dependency that pnpm 11 rejects in consumer installs.
- The release preflight uses the macOS `.dylib` filename for its native smoke test.

## Verification

- Frozen-lockfile installation, configured lint, and production build passed.
- `pnpm test:all` passed after the final CLI fixes. It now includes
  `tests/test-cli-package.js`, covering scaffold version, namespace-only starter
  execution, redirect behavior, and serving the runner and selected cart.
- The release preflight passed all blocking gates on its corrected run with
  `--release --skip-build`, reusing the already successful production build.
- Host macOS RetroArch compilation and all three smoke carts passed.
- The final tarball installed in an isolated pnpm 11 consumer. That consumer
  approved the required esbuild and msgpackr-extract build scripts locally.
- Init and template creation selected version 0.5.3. The CLI regression also
  passed with `NOVA64_PACKAGE_ROOT` pointing at the installed tarball.
- Browser verification of the installed starter showed a rendered cube and
  successful cart initialization after fixing the missing-function errors.
- Archive checks confirmed expected assets, the console delistings, and absence
  of private operations documents and `.env` paths. Publish dry run passed.

## Artifact and limits

The local, gitignored release directory is `nova-release/npm-0.5.3/`. It contains
the tarball, SHA256 checksum, logs, screenshot, and publication instructions.
The original archive was 255.4 MB with 1,155 files. Its SHA256 was:

```text
33465b5a12892bf0f5aa4e9a771108cf856d7d2ade2a8e8a2191a863070ad5fc
```

This checksum identifies the tested artifact before this documentation update;
repacking after later changes produces a new artifact that needs verification.
The registry subsequently rejected that archive with HTTP 413. It is retained
locally as `rejected-oversize.tgz`, not as the publication candidate.

The replacement excludes duplicated `public/` assets, prebuilt `.nova` exports,
and source maps. Public assets remain in `dist/`, and installed CLI development
serves them from there. The package regression checks the shell's asset route
as well as the selected cart. Browser verification confirmed the installed
starter still renders. The replacement's checksum is recorded alongside the
tarball in `SHA256SUMS.txt`.

Repository-wide formatting remains a warning-only failure. Supplemental CLI lint
reports two pre-existing unused imports in `template.js`; configured release lint
passes. The runtime startup banner still reports an older version, while npm
metadata is 0.5.3. These observations were not changed as part of packaging.

The cross-platform native CI matrix was not run. The native smoke covers this
Mac and software 2D output; it does not establish rendering parity on other
platforms. This was a release-focused review, not an exhaustive audit of every
cart or backend. Tracked build output was subsequently committed at the user's
explicit request; release archives remain gitignored.
