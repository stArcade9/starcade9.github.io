# Nova64 v0.2.0

**Released:** 2026-03-19

The move to a real 3D rendering pipeline. Nova64 transitions onto Three.js and
gains the material, lighting, and UI systems that the demo gallery is built on.

## Highlights

- **Three.js integration** — complete transition to the Three.js rendering
  pipeline.
- **Advanced materials** — holographic, metallic, and emissive materials.
- **Cinematic lighting** — multi-layered lighting with 4K shadow mapping.
- **UI system** — buttons, panels, fonts, progress bars, and start screens.
- **8 demo carts** — the initial demo gallery.
- **Tooling** — benchmark suite, instancing demo, and a clean ESLint pass across
  `runtime/` and `src/`.
