# Nova64 v0.5.8

Re-cuts v0.5.7 using the replacement npm publishing credential. All ten v0.5.7
platform cores built successfully, but npm rejected the old credential, so
v0.5.7 was published only as a GitHub Release with core downloads.

The runtime is unchanged from [v0.5.7](v0.5.7.md): RetroArch web support, QWEN
Arcade, rendering and Godot improvements, Babylon compatibility repairs, and
namespace fixes for example carts.

The release still requires all platform core builds and the npm validation
steps to pass before npm publication.

```bash
pnpm add nova64@0.5.8
pnpm dlx nova64@0.5.8 --help
```
