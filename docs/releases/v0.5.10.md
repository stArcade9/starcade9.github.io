# Nova64 v0.5.10

Released November 9, 2026.

This patch brings the new Nova64 homepage, two vivid racing demos, procedural
skies and Babylon rendering improvements to the npm package.

## Highlights


- **New installed homepage:** `nova64 --start-demo` opens the Nova64 marketing
  homepage with Disc Vault game links, refreshed thumbnails and a bundled demo player.
- **Breakwater Circuit:** original antigravity Quick Race and Time Trial with
  five AI rivals, three laps, Slip Charge, recovery and saved best times.
- **F-Zero Nova:** a ringed planet, orbital city, violet atmosphere and stronger
  UnrealBloom, with boost-responsive distortion and the original endurance gameplay.
- **Procedural skies:** reusable sky presets, camera-following skies, animated
  atmosphere and sky-driven PBR reflections. Multiple carts now match fog to
  their horizon; bright-sky bloom washout is corrected in Space Harrier and
  Super Plumber 64. The plumber also has a rebuilt animated character.
- **Babylon parity:** shared procedural sky shaders, sky reflections and animation,
  corrected ambient lighting, a bundled production console, and an engine switch
  that retains the current cart.
- **Launchers and input:** Breakwater is available in the console, embed and OS
  shell launchers. Gamepad face-button presses survive overlapping Start/Select aliases.

## Install or update

```sh
pnpm add nova64@0.5.10
pnpm dlx nova64@0.5.10 --start-demo
```

The release workflow builds all native core targets before publishing npm.
UnrealBloom uses the Three.js path; Babylon does not provide identical effects.
The separate nova64.io deployment is not part of this npm release.

Known non-blocking local-homepage requests remain: the Vercel analytics script
and a transient hero template placeholder may return 404 when served locally.
The optional emissive-material changes and asset deduplication are deferred.

## Publication verification

The public registry reports `latest: 0.5.10`. A clean registry installation
passed the installed-CLI regression and browser checks for the homepage, all
22 Disc Vault link destinations, Super Plumber via the vault, the engine switch,
and Space Harrier using Babylon. The two local-homepage 404s noted above remain.

All ten native core targets passed in the
[release run](https://github.com/seacloud9/nova64/actions/runs/42771516235).
The upload succeeded, but that run's one-minute visibility check timed out while
npm reported `validating`. npm subsequently reported `published`; a
[follow-up authenticated check](https://github.com/seacloud9/nova64/actions/runs/42773008984)
passed. The macOS download also matched its published SHA256 checksum. Future
release checks now allow ten minutes for npm processing. No force publish or
local republish was needed.
