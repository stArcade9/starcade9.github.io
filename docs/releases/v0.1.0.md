# Nova64 v0.1.0

**Released:** 2026-03-19

First public release of Nova64 — the JavaScript 3D fantasy console. This is the
genesis cut: the 2D core, the WebGL2 backend, and the cart model that everything
since is built on.

## Highlights

- **Core 2D API** — pixel-perfect graphics with RGBA64 precision.
- **WebGL2 backend** — hardware-accelerated rendering.
- **Sprite system** — batched rendering with animation.
- **Physics & audio** — 2D physics and WebAudio synthesis.
- **Cart lifecycle** — the `init()` / `update(dt)` / `draw()` model carts still
  use today.

## Notes

This tag is the initial import (106 commits, largely un-messaged as the engine
took shape). Later releases add the Three.js pipeline (v0.2.0), the grouped
`nova64.*` namespace and Godot host (v0.4.9–v0.5.0), and cross-platform binaries
(v0.5.2+).
