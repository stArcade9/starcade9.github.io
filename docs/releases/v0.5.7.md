# Nova64 v0.5.7

**Status:** Unreleased

This patch brings the libretro core to the browser, expands rendering support,
and repairs cart and backend compatibility since v0.5.6.

## Highlights

- **RetroArch on the web:** WebAssembly core, browser player, and OS shell
  integration. The core loads from its asset directory even when the player is
  embedded under a different page URL.
- **QWEN Arcade:** games made with a local Qwen model, with mobile shell access
  and touch controls.
- **Rendering:** PBR reflections and refraction, HDR skyboxes, and POV-Ray 1995
  mode. Godot gains environment skyboxes, tone mapping, and physical point lights.
- **Compatibility:** restored Babylon mesh options, colours, and bloom; removed
  duplicate mesh setters that shadowed the restored implementations. Repaired
  example carts affected by the namespace migration.
- **Stability:** Godot media playback and teardown fixes, repeated cart errors
  logged once, and UTF-8 text drawn as one glyph per codepoint in the native core.
- **Release tooling:** Node 24 toolchain, native core checks on pull requests,
  and a normalized npm CLI executable path.

## Install after publication

```bash
pnpm add nova64@0.5.7
pnpm dlx nova64@0.5.7 --help
```

The npm package and platform cores publish through the tag-triggered release
workflow after all platform core builds succeed. Patreon downloads use the same
zip as the Lemon Squeezy bundle.
