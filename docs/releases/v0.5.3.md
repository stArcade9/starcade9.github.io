# Nova64 v0.5.3

**Released:** 2026-07-06

Two big threads land in this 145-commit release: the **Metaverse** — a shared 3D
world with multiplayer, auth, and voice chat that cross-plays web ↔ Godot — and
the **distribution pipeline**: a one-command Lemon Squeezy release build,
standalone desktop exports, iOS/tvOS cores, and a green-before-you-push CI
preflight.

## Highlights

### Metaverse — shared 3D world

- Phase 1 shared world on `nova64.net`; extensible framework with a pluggable
  render backend, UI components, plugins, and chat.
- Cross-play: ES module loader + native Godot text chat (`nova64.gdtext`) so the
  metaverse runs web ↔ Godot; host-selected render backends.
- **Auth** — Supabase auth, wallet sign-in (EVM SIWE / EIP-4361), `nova64.auth`
  identity wiring (display name + provider + stable color); `verifyToken`
  onAuth gate unit-tested.
- **Multiplayer** — presence (floating name tags, join/left toasts, distance-fade
  tags), live player roster, `/nick` live rename + persistence, avatar color
  sync, hardened relay (payload cap + per-client rate limit).
- **Voice** — WebRTC push-to-talk voice chat.
- Plugins: minimap radar, emotes; one-command test runner (`pnpm test:metaverse`).

### Distribution — Lemon Squeezy

- **One-command unified export build** for Lemon Squeezy (`pnpm release:lemon`):
  desktop apps + RetroArch cores + Godot source in a single upload zip.
- Standalone desktop (`.exe` / Linux) exports for buyers.
- Fetch Android/RPi/macOS/Apple cores from the GitHub Release into the bundle.
- Homepage Lemon Squeezy checkout wired into the landing CTA.

### Platform cores

- iOS/iPadOS (arm64) and tvOS RetroArch cores build in CI.

### CI / release safety

- **`pnpm release`** one-shot: validate → bump → commit → tag (never pushes).
- Pre-push preflight (`pnpm ci:check`) so CI is green before it hits GitHub;
  npm publish only after every platform core builds green; host RetroArch core
  compiled in the `--release` preflight. Node heap raised to 8 GB so the build
  doesn't OOM.
- **Secure commits** — a hook blocks commits containing staged secrets.

### Carts & mobile

- Cinematic `the-last-save-file` cart + `cls3D` / `glitchBurst` host helpers;
  real screen-shader glitch (`fx.glitch`) replacing the 2D overlay fake.
- Portrait gate that pauses the cart and asks to rotate; mobile-tappable
  boot prompts; multi-touch parity (`nova64.input.touches()`) on Godot.
