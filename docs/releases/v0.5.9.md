# Nova64 v0.5.9

Re-cuts v0.5.7 using the verified `NOVA64IO` publishing credential. The v0.5.8
attempt was canceled when its replacement credential failed authentication.
There are no runtime changes since [v0.5.7](v0.5.7.md).

Highlights include RetroArch web support, QWEN Arcade, PBR reflections and HDR
skyboxes, Godot rendering and stability improvements, restored Babylon mesh
behaviour, and repaired example carts.

All platform core builds and npm validation steps must pass before publication.

```bash
pnpm add nova64@0.5.9
pnpm dlx nova64@0.5.9 --help
```
