# Nova64 v0.5.11

This patch ships the post-release bloom correction and refreshed npm README.

- Three.js materials honor explicit `intensity` and preserve the mesh palette
  for `emissive: true`; emissive materials without a separate glow color use
  their mesh color. Cached materials distinguish different emission intensities.
- The legacy shading model, opacity and global bloom settings remain unchanged.
  Hardware-GPU before/after checks cover the affected demos, with matched
  gameplay captures confirming the approved F-Zero presentation is retained.
- The README now leads with installation, current demos, the cart API and host
  support, with direct links to [nova64.io](https://nova64.io/) and the
  [live documentation](https://nova64.io/docs).
- The release workflow allows more time for npm to validate an accepted upload;
  an authenticated diagnostic exposes package processing status.

```sh
pnpm add nova64@0.5.11
pnpm dlx nova64@0.5.11 --start-demo
```

The material correction is specific to the Three.js compatibility path. Babylon
still uses its existing emission behavior. The separate nova64.io deployment is
not part of this npm release. Known local-homepage analytics and hero-placeholder
404s are unchanged from v0.5.10.
