# Nova64 v0.5.1

**Released:** 2026-05-10

A focused Godot parity push (103 commits): the native host closes most of the
remaining visual gaps against the Three.js reference for voxel, WAD, VOX, PBR,
and shader carts, and the in-editor JS authoring experience improves.

## Highlights

### Godot visual parity

- **Voxel/Minecraft parity** — native `voxel.uploadChunk` face-culled chunk
  mesher (Phase 1) + greedy meshing (Phase 2), atlas UV texturing, simplex
  terrain alignment, biome heights + world seed, dynamic chunk streaming for
  infinite terrain, and tree-material parity.
- **WAD parity** — Phase 3 wall textures, `uvOffset`, `getCamera`, sector
  lighting; sprite-billboard flip/orientation fixes; GLB + VOX asset parity.
- **Lighting/color parity** — phase-4 dynamic lighting animation; tonemap
  exposure and fog/background color tuned to match the Three.js knee.
- **Shader / HYPE / particles / Flash** demos brought to parity.

### Cart runtime parity in the Godot shim

- Real tween engine, full gameutils, `createGameStore` / `novaStore`.
- `nova64.ui` `drawText` / `setFont` / `setTextAlign` and instanced-mesh API on
  `nova64.scene`.
- `wizardry-3d` playability: `setCameraLookAt`, color/draw helpers, mesh
  visibility, encounter utilities.
- F-Zero start-screen camera aligned with gameplay (no perspective jump).

### Authoring & loader

- **Godot editor** — JS syntax highlighting + ESLint for cart `code.js` files.
- **Loader** — accept `?cart=` as an alias for `?demo=`.
- Continued cart + runtime migration to the grouped `nova64.*` namespace.
