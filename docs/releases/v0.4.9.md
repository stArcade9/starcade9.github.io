# Nova64 v0.4.9

**Released:** 2026-04-29

A very large release (270 commits) spanning the v0.3.x/v0.4.x line into trunk.
Two headline efforts land here: the **native Godot host** merges to trunk, and
the **Babylon.js backend** reaches broad parity with Three.js. This release also
introduces the grouped `nova64.*` namespace API that becomes the canonical
cart-facing contract.

## Highlights

### Godot native host — merged to trunk 🎉

- The GDExtension (`nova64-godot/gdextension/`), QuickJS bridge, cart shim,
  conformance harness, and visual-parity tooling become part of the main build.
  Nova64 carts run end-to-end through a native Godot 4.x host.
- Carts running natively: `minecraft-demo`, `f-zero-nova-3d`, `star-fox-nova-3d`,
  `space-harrier-3d`, `fps-demo-3d`, plus the 00–10 conformance series.
- `fps-demo-3d` ships a Godot-side WAD start-screen map picker loading
  `freedoom1.wad` through `nova64.wad.load()`.
- Native voxel work: full 22-function voxel API in the JS shim over a
  sparse-Map + heightmap model, 3-octave noise terrain, 8-biome classification,
  and MultiMesh-batched rendering out to 64×64 columns.

### Babylon.js backend parity

- GPU instancing API, `SolidParticleSystem`-based particles, TSL procedural
  shader materials, advanced glitch shader, and voxel texture-atlas UV parity.
- `Framebuffer64` support and right-handed coordinate system to match Three.js
  player controls and 2D framebuffer compositing.
- Native WebXR VR/AR + Cardboard fallback and MediaPipe hand/face/pose tracking.

### `nova64.*` namespace API

- New grouped namespace (16 sub-namespaces) with destructuring collision
  guardrails; examples migrated off flat ESLint globals.

### Other

- Environment-aware logging (dev/production modes).
- MagicaVoxel `.vox` format support in the OS9 Model Viewer.
- TSL Shader Pack Phase 1 — procedural material presets + single-shader viewer.
- Adapter contract stabilized (capabilities, command-buffer, conformance tests).
- Version history moved to `CHANGELOG.md`; Playwright test infrastructure added.
