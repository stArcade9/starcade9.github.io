stArcade9 provides these instructions for players of Emberbound, including the Facebook Instant Game with app ID 1186459093950171.

Delete saved game data

  1. Open Emberbound in the browser or Facebook account you used to play.
  2. Open the game's Settings using the gear button.
  3. Select Delete saved data, then Yes, delete saved data.
  4. After deletion succeeds, the game reloads with a new campaign. Your saved progress, inventory, selected hero and preferences on that browser have been removed.

When Meta's player-storage API is available, this action also clears the current Meta copy of your Emberbound progress. It waits for earlier game-save writes to finish before clearing that copy. If a supported Meta storage call fails, the game shows an error so you can retry.

Deletion cannot be undone. A later play session can create a new save. Local game data is device-specific: repeat deletion on each browser or device where you played. If Meta does not expose its storage API in your current environment, the action clears local data only; contact us or use Meta's controls for additional help.

If the game cannot open

You can remove local game data using your browser's site-data controls for the Emberbound game page. This affects the current browser; it does not automatically clear a copy stored by Meta. To request help with data you sent directly to stArcade9, email us as described below.

Remove Meta app access

Use Facebook's Apps and websites settings to find Emberbound and remove its access. Follow any data-deletion options Meta provides. Removing access does not by itself clear browser storage or delete your Facebook account. Meta handles its own account and platform records under Meta's Privacy Policy.

Request assistance or deletion of support messages

Email brendonsmith@seacloud9.org with the subject Emberbound data deletion request. Describe the data you want removed and whether you played in a standalone browser, Facebook or Messenger. If you are asking us to remove support correspondence, use the same email address you originally contacted us from when possible.

We will review the request and explain any further steps needed to identify data we control. We do not operate a separate gameplay database and cannot directly delete Meta's own platform records. Never send your password, app secret or access token. We may request the minimum non-sensitive information needed to verify a request, and will explain any limits that apply.

For more information, read the Emberbound Privacy Policy.
